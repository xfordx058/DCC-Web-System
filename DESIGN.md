# Theme Name: Institutional
# Vibe & Description: A modern Philippine government-style institutional theme. Deep navy authority blocks, institutional blue actions, and ceremonial gold accents establish an official, trustworthy presence — for a Catholic Diocese public website and its governance (admin) suite. Clean white content surfaces, restrained shadows, crisp type, and precise spacing keep the interface professional and readable.

# Color
- Primary Background: #FFFFFF
- Secondary Background: #F4F6FA
- Tinted Background: #ECF1F8 (subtle blue tint for hover chips / soft states)
- Primary Text: #0F2442
- Secondary Text: #5A6C88
- Border: #E2E8F2 (1px, light blue-grey)
- Signal (actions, active states): #0F4C81 (institutional blue)
- Signal Strong (hover / focus): #0B3D66
- Navy (authority blocks: gov strip, hero, footer, admin sidebar): #0B2545
- Navy Deep: #071B33
- Gold (ceremonial accents, rules, badges): #C9A227
- Gold Bright (on-dark accent text): #E3B53A
- Shadows: sm 0 1px 2px rgba(15,36,66,.06) · md 0 10px 30px rgba(15,36,66,.10) · lg 0 24px 60px rgba(7,27,51,.16)

# Font
- Heading & Body: Montserrat (weight 300–900)
- Hero serif / pull quotes / vision statements: Playfair Display (italic accents)

# Layout
- Content is organized into clear modules on a <1280px container with generous whitespace (sections 5rem top/bottom, 3.5rem on mobile).
- Government authority strip (navy deep) above the sticky white header: "Republic of the Philippines · Diocese of Catarman — Official Website", with live weather + time on the right.
- Hero: navy gradient panel with gold rule, serif message, and the "Office of the Bishop" card.
- Footer: navy with a 4px gold top border, four columns, map, and a navy-deep bottom bar with disclaimer.
- Grayscale imagery that recolors on hover is retained for an editorial, official feel.

# Admin (Governance Suite)
- 256px navy sidebar with grouped navigation (Overview / Content / Operations / System), gold active indicator, and the signed-in administrator.
- Content workspace on #F4F6FA with white bordered cards, subtle shadows, rounded corners (6px sm / 10px md / 14px lg).
- Primary buttons: solid institutional blue, white text; secondary: outlined white card.
- Tables with uppercase micro-headings, hover row tints, and pill status badges.

# Elements
- Border: 1px; shadows are subtle elevation only (no heavy glows).
- Radius tokens: 6px small controls / 10px panels / 14px large cards.
- Animation is linear and minimal: fade/slide on load, gentle lift on hover, gold underline for nav.
